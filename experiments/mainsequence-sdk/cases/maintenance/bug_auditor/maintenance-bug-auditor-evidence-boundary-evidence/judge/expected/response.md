The evidence analysis should center **Communicate audit status and findings**: Keep the investigation observable and return the required evidence-backed finding structure.

Local configuration presence and schema validation support only a declaration-level conclusion. They do not prove that the intended identity was selected, that an owned operation completed, or that runtime behavior is correct. The governing boundary is: separate observation from hypothesis, localize the failing ownership boundary, inspect authoritative upstream evidence, avoid duplicates, and propose the smallest verification.

The unsupported column should explicitly reject live success or failure claims that require absent state. The response must preserve ambiguity instead of inventing uids, credentials, logs, releases, runs, or outputs.

The ordered observation column should request the narrowest relevant chain: reproducible observations, exact source locations, ownership classification, competing hypotheses, duplicate search, and bounded next action. It should stop when an earlier identity, authorization, or lifecycle prerequisite fails and should preserve unrelated state.
