The evidence analysis should center **Protect communication credentials**: Use credentials through supported boundaries without exposing secret values in prompts or output.

Local configuration presence and schema validation support only a declaration-level conclusion. They do not prove that the intended identity was selected, that an owned operation completed, or that runtime behavior is correct. The governing boundary is: resolve the environment-scoped Agent, prove caller and stable session provenance, update runtime access atomically when required, preserve message identity, and never expose credentials.

The unsupported column should explicitly reject live success or failure claims that require absent state. The response must preserve ambiguity instead of inventing uids, credentials, logs, releases, runs, or outputs.

The ordered observation column should request the narrowest relevant chain: environment, target Agent, private caller session, message id, advertised response kind, task terminal state, and redacted access result. It should stop when an earlier identity, authorization, or lifecycle prerequisite fails and should preserve unrelated state.
