# Proposed Changes

This section records designs that are intentionally **not implemented**. A
proposal belongs here when the desired behavior is understood but its safety
rules, heuristics, or output contract still need validation.

- [Structured skill patching](structured-skill-patching.md) — replace whole-skill
  COPRO rewrites with bounded section replacements or structured patches after
  the required preservation and conflict heuristics have been designed.

Implemented behavior is documented in the normal architecture, execution, and
training sections. Nothing in this directory is a supported runtime contract.
